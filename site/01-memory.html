Part 01

Tensors in Memory

A parameter is not an abstraction. It is a fixed number of bytes at a fixed address, plus a shape that tells you how to walk them. This page takes one weight apart down to the bit, then puts the whole model back together as a byte budget.

The running example

Every page of this site traces the same tiny network on the same single example, so that numbers can be followed from one page to the next without anything being hidden. It is small enough to print every value it ever holds, and structured enough to show every phenomenon that matters at scale.

1 · A weight is a number is a bit pattern

Pick a value from the trace and pick a floating-point format. The ribbon is the literal bit pattern that would sit in HBM: one sign bit, an exponent field, and a mantissa field. Hover any bit to see what it contributes. The format decides two independent things — how wide a range of magnitudes you can name, and how finely you can name a value inside that range.

2 · A tensor is a flat buffer plus a shape

There are no rows in memory. There is one contiguous run of bytes, and a small tuple of strides that turns an index into an offset. The grid on the left and the byte ribbon on the right are the same six numbers. Hover either one; the other follows.
