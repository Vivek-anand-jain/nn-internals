PagedAttention: the KV cache needed an operating system

The KV cache is per-sequence, it grows one token at a time, and nobody knows how long it will get. A contiguous allocator has exactly one safe move — reserve the advertised context up front — and on realistic traffic most of that reservation is never touched. PagedAttention replaces it with fixed-size blocks, a block table per sequence and allocation on demand. This page allocates the same requests both ways, block by block, and counts what the change is worth.
